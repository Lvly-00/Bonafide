# Bonafide Frontend

React 19 + Vite + TypeScript SPA for the Bonafide tutoring platform.

See the [root README](../README.md) for full setup instructions and feature documentation.

## Quick Start

```bash
npm install
cp .env.example .env   # set VITE_API_URL=http://localhost:8000/api
npm run dev
```

App runs at `http://localhost:5173`.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Production build (`tsc -b && vite build`) |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run oxlint |
